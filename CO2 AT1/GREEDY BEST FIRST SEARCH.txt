ALGORITHM: GREEDY BEST FIRST SEARCH

	INPUT:
		Graph - G(V, E)
		Source node - (S)
		Goal node - (G)
		Heuristic function - (h(n))
	OUTPUT:
		Path from source to goal.

	STEPS: 
		1. Start from the source node.
		2. Create an OPEN list and insert the source node.
		3. Create an empty CLOSED list.
		4. Repeat until OPEN is empty:
			a. Remove the node having the smallest heuristic value.
			b. If the node is the goal, stop and return the path.
			c. Otherwise: Move the node to CLOSED.
				i. Expand all unvisited neighboring nodes.
				ii. Compute or assign their heuristic values.
				iii. Insert them into OPEN.
				iv. Sort OPEN according to increasing heuristic values.
		5. If OPEN becomes empty before reaching the goal, report No Path Exists.
