ALGORITHM: CONSTRAINT SATISFACTION PROBLEM (CSP) FOR EXAM TIMETABLING
	
	INPUT:
		Subjects - (S = {S1, S2, ..., Sn})
		Available Time Slots - (T = {T1, T2, ..., Tm})
		Constraints (conflicting subjects, room availability, etc.)

	OUTPUT:
		A conflict-free examination timetable.

	STEPS:
		1. Identify each subject as a variable.
		2. Assign the available examination time slots as the domain for each variable.
		3. Define the constraints:
			◦ Conflicting subjects must not be assigned the same time slot.
			◦ Each subject must be assigned exactly one time slot.
		4. Select the unassigned variable using the Minimum Remaining Values (MRV) heuristic.
		5. Assign a valid time slot from its domain.
		6. Apply Forward Checking:
			◦ Remove the assigned time slot from the domains of all conflicting neighboring subjects.
			◦ If any neighboring subject has no remaining valid time slot, backtrack.
		7. Repeat Steps 4–6 until all subjects are assigned valid time slots.
		8. If all variables are assigned successfully, return the examination timetable.
		9. If no valid assignment exists, report No Solution Exists.
