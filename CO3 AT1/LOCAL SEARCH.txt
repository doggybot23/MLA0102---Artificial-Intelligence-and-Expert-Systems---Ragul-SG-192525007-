ALGORITHM: ONLINE SEARCH AGENT

	INPUT:
		• Environment (Grid/Map)
		• Start Position (S)
		• Goal Position (G)
		• Obstacles

	OUTPUT:
		• Path from the start position to the goal.

	STEPS:
		1. Start the robot at the source position.
		2. Observe the current environment and identify neighboring positions.
		3. If the goal is reached, stop and return the path.
		4. Select the best available neighboring position that is free of obstacles.
		5. Move the robot to the selected position.
		6. Continuously sense the environment for newly appearing obstacles.
		7. If an obstacle blocks the current path:
			◦ Recalculate the next best move using the updated environment.
			◦ Avoid the blocked position.
		8. Repeat Steps 3–7 until the goal is reached.
		9. If no valid path exists, report No Path Exists.
